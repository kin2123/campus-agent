# 考试管理与成绩评定规定

## 一、考核方式

课程考核分为两种形式：

- **考试**：以闭卷或开卷笔试为主，成绩按百分制记载
- **考查**：以课程论文、项目、平时表现为主要依据，成绩可按百分制或五级制记载

具体采用哪种形式，见课程大纲。查询某门课的考核方式，可在课程详情中查看「考核方式」字段。

## 二、成绩构成

考试课的最终成绩一般构成如下（具体比例以课程大纲为准）：

| 构成项 | 常见比例 |
|---|---|
| 平时成绩（出勤、作业、课堂表现） | 20% - 40% |
| 期中考试 | 0% - 20% |
| 期末考试 | 40% - 60% |

**重要**：部分课程设置「平时成绩不合格不得参加期末考试」的门槛。缺课累计超过该课程总学时 1/3 的，取消考试资格，成绩记 0 分并标注「缺考」。

## 三、成绩等级换算

| 百分制 | 五级制 | 绩点 |
|---|---|---|
| 90 - 100 | 优秀 | 4.0 |
| 80 - 89 | 良好 | 3.0 - 3.9 |
| 70 - 79 | 中等 | 2.0 - 2.9 |
| 60 - 69 | 及格 | 1.0 - 1.9 |
| 0 - 59 | 不及格 | 0 |

绩点精确换算公式：60 分及以上为 `(分数 - 50) / 10`，60 分以下为 0。

## 四、考试安排与纪律

- 期末考试安排在每学期最后两周，具体时间由教务处统一编排，考前 2 周在教务系统公布
- 考生须携带学生证或身份证入场，无证件不得参加考试
- 开考 30 分钟后不得入场，开考 60 分钟内不得交卷离场

**违纪处理**：

| 行为 | 处理 |
|---|---|
| 携带手机等电子设备未按规定放置 | 按违纪处理，该科成绩记 0 分 |
| 夹带、抄袭、传递答案 | 按作弊处理，该科成绩记 0 分，给予记过处分 |
| 替考、组织作弊 | 开除学籍 |

考试违纪与作弊记录会进入学生档案，**直接影响推免、评优、入党、公务员政审**。

## 五、缓考

因疾病或特殊原因无法参加考试的，可申请缓考：

1. 考前提交《缓考申请表》，附二级甲等以上医院证明或其他有效证明
2. 经院系审核、教务处批准后生效
3. 缓考安排在下一学期开学第 2 周，与补考同时进行
4. 缓考成绩按实际得分记载，不折减

**考前未办理缓考手续且缺考的，一律按缺考记 0 分**，事后补办不予受理。

## 六、成绩复核

对成绩有异议的，可在成绩公布后 **10 个工作日内**提出复核申请：

1. 向开课院系教学秘书提交《成绩复核申请表》
2. 复核范围仅限「登分错误、漏批、合分错误」，不重新评阅答卷内容
3. 复核结果在受理后 5 个工作日内答复

## 七、成绩单与证明

- 在校生可在一站式服务大厅自助打印机打印中英文成绩单（前 3 份免费）
- 已毕业学生需通过档案馆申请，5 个工作日内出具
- 成绩单上「W」表示退课，「F」表示不及格，「I」表示缓考未出分

## 八、绩点与排名

- 平均学分绩点（GPA）采用加权平均：`Σ(课程绩点 × 学分) / Σ学分`
- 专业排名在每学期成绩全部录入后 1 周内更新，可在教务系统查询
- 排名用于评奖评优、推免、交流项目选拔
- 重修成绩计入 GPA 时按最高成绩计算，但部分评优项目要求「首次修读成绩」

## 九、常见问题

**Q：补考通过了成绩单上显示多少分？**
A：显示 60 分，并标注「补考」。

**Q：重修会不会影响 GPA？**
A：重修成绩替换原成绩计入 GPA，取最高分。但成绩单会保留两次记录。

**Q：成绩什么时候能在系统里看到？**
A：任课教师在考试结束后 2 周内录入，逾期未录入可向开课院系反映。

**Q：毕业班最后一学期挂科了怎么办？**
A：可参加结业后补考，一般在 7 月进行，通过后换发毕业证。具体时间以教务处当年通知为准。
